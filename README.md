# Entrega TP4 - Página web - 1º cuatrimestre 2026
Este trabajo consiste en el rediseño y desarrollo de una página web de cines argentinos. 
Cuenta con una página inicial, y páginas secundarias donde podrán ver los horarios, los próximos estrenos y la información principal de cada película (la cual te lleva a las páginas oficiales de los cines mencionados). 
La página fue primero diseñada en Figma y luego desarrollada con HTML y CSS en Visual Studio Code, con varias herramientas de Flexbox para 
un diseño más flexible. El tamaño de pantalla utilizado en Mac es de 1280x800px y en Windows 1920x1080px. Link a figma: https://www.figma.com/design/0KBADeqzFQmrOyeglMYbqe/G4---Cines-Argentinos?m=dev
